# 🎓 Smart-Teacher | Multi-Game Learning Platform

Smart-Teacher is a fully static, frontend-only web application designed to help students learn English through interactive games and AI-powered assistance.

## 🎮 Games Included
- **🚀 Space Shooter**: Translate words while defending your ship.
- **🍄 Mario Learning**: Classic platformer with English grammar questions.
- **🥊 Word Battle**: Defeat enemies by answering vocabulary challenges.
- **⛏️ Minecraft**: Mine blocks by translating Uzbek words to English.
- **📚 Scramble, Quiz, Emoji, & more**: Quick-fire learning modules.

## 🚀 Features
- **Frontend-Only**: No backend required. Can be hosted on GitHub Pages, Netlify, or Render.
- **AI Integration**: Uses Google Gemini 1.5 Flash to generate dynamic content.
- **Responsive Design**: Works on both desktop and mobile devices with touch controls.
- **Premium UI**: Modern aesthetics with glassmorphism and smooth animations.

## 🛠️ Setup
1. Clone the repository or download the files.
2. Open `index.html` in any modern web browser.
3. Enter your name when prompted.
4. Enter your **Google Gemini API Key** to enable AI features.

## 🌐 Deployment
This project is ready to be deployed as a **Static Site**.

### Deploy to Render
1. Create a new **Static Site** on Render.
2. Connect your GitHub repository.
3. Set the **Build Command** to: `(none)` (leave empty).
4. Set the **Publish Directory** to: `.` (root).

### Deploy to GitHub Pages
1. Push your code to a GitHub repository.
2. Go to **Settings > Pages**.
3. Select the `main` branch and `/root` folder as the source.
